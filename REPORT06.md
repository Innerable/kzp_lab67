# Звіт до лабораторної роботи № 6

## 1. Тема, номер і варіант

- **Лабораторна:** № 6. **Варіант:** 6 — реєстр студентів.
- **ОС:** Arch Linux. **Python:** 3.14 (мінімум за `pyproject.toml` — 3.11); CI — 3.12.
- **Репозиторій:** https://github.com/Innerable/kzp_lab67

## 2. Мета роботи
Створити Python-пакет `kzp_lab06`, який читає CSV, перетворює поля на типи, будує звіт за
списками, словниками й множинами та записує його у файл UTF-8. Пакет поділено на модулі,
помилки обробляються явно, поведінку перевіряє `pytest`, якість — `ruff`, пакет збирається у wheel.

## 3. Формат CSV
Заголовок: `full_name,group,year,average`.

| Поле | Тип | Правило |
|---|---|---|
| `full_name` | str | непорожнє |
| `group` | str | непорожнє |
| `year` | int | 1–6 |
| `average` | float | 0–100, не NaN |

Приклад рядка з екрануванням: `"Шевченко, Тарас",КІ-302,2,95.0`.
**Порожній вхід:** файл лише із заголовком дає порожній список і звіт із нулями;
файл без заголовка або без обов'язкового стовпця — `DataError`.

## 4. Структура модулів

| Модуль | Призначення |
|---|---|
| `errors.py` | `DataError` |
| `loader.py` | `load_records`: `csv.DictReader`, UTF-8, `newline=""`, типи, номер рядка в помилках |
| `analysis.py` | відбір, групування, множина груп, середній бал, найкращий запис, `summarize` |
| `reporting.py` | `format_report` (текст) і `write_report` (файл) |
| `cli.py` | аргументи, коди завершення; код запуску захищено `if __name__ == "__main__"` |

`loader` не друкує, `analysis` не відкриває файли, `reporting` не читає CSV.

## 5. Перетворення даних
- Список: `list[dict]` записів; **comprehensions:** відбір `[r for r in records if average >= threshold]`,
  множина `{r["group"] for r in records}`, словник `{group: counts[group] for group in sorted(counts)}`.
- Словник: кількість студентів за групою. Множина: унікальні групи.
- Типи: `year → int`, `average → float`, текстові поля обрізаються від пробілів.

## 6. Функції
`summarize(records, *metrics, minimum_average=0.0, **labels)`:
- `*metrics` — назви числових полів (`year`, `average`), невідому відхиляє `ValueError`;
- `minimum_average=0.0` — типове значення (незмінний об'єкт);
- `**labels` — підписи результатів.

```python
summarize(records, "average", "year", minimum_average=90.0, average="Сума")
# {'count': 2, 'Сума': 185.0, 'year': 6.0}
```

## 7. Алгоритм аналізу
Відбір: `average >= 90` (межа 90.0 входить). Агрегування: кількість за групою з ключами у
алфавітному порядку. Унікальні значення: множина груп. Найкращий результат — найвищий бал,
за рівності — менший ПІБ. Порядок рядків звіту не залежить від порядку рядків у файлі.

## 8. Обробка помилок
`DataError` містить номер фізичного рядка й назву поля; першопричину зберігає `raise ... from`
(`ValueError`, `OSError`, `csv.Error`). Голого `except` немає.

| Код | Значення |
|---|---|
| 0 | успіх |
| 1 | помилка даних (повідомлення в stderr, UTF-8) |
| 2 | помилка запису звіту |

## 9. Файловий звіт
Запис через `with path.open("w", encoding="utf-8", newline="\n")`, каталог створюється
`mkdir(parents=True, exist_ok=True)`. Звіт на `data/input.csv`:

```text

Відібрано (середній бал >= 90.0): 4
Групи: КІ-301, КІ-302, КІ-303, КІ-501
Кількість за групою:
  КІ-301: 2
  КІ-302: 2
  КІ-303: 2
  КІ-501: 2
Середній бал: 86.44
Найкращий результат: Ткаченко Оксана (КІ-501) — 98.50
```

## 15. Відповіді на контрольні питання
- **Навіщо `pyproject.toml`?** Описує пакет, залежності, скрипти й налаштування інструментів в одному місці.
- **Чому `csv`, а не `split(",")`?** Модуль розуміє лапки й коми всередині полів.
- **Що робить `with`?** Гарантує закриття файла, навіть якщо під час запису виникає виняток.
- **Чому небезпечний порожній `except`?** Ховає причину помилки й ловить навіть `KeyboardInterrupt`.
